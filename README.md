# SOC Phishing Analysis

## Project Overview
A hands-on cybersecurity training project completed as part of the TryHackMe SOC Level 1 learning path, focusing on phishing investigation and security reporting.

## Tools and Technologies
- Mozilla Thunderbird
- Ubuntu Linux
- WHOIS
- MXToolbox
- VirusTotal
- SHA256 Hashing

## Skills Demonstrated
- Phishing email analysis
- Email header analysis
- SPF and DMARC interpretation
- IP address investigation
- File hash analysis
- Threat intelligence
- Incident triage and reporting

## Project Report
[View Phishing Investigation Portfolio Report](./Phishing_Investigation_Portfolio.pdf)

## Learning Outcomes
Developed practical knowledge of suspicious email investigation, malware reputation analysis, security documentation and incident response procedures.

## Disclaimer
This project represents hands-on learning in a controlled training environment, not professional work experience or a live organisational incident.

Challenge-specific answers and sensitive lab evidence have been intentionally excluded.
